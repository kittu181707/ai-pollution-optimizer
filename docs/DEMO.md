# Demo runbook

1. Load demo day.
2. Review the fixed agenda.
3. Confirm the supplied travel modes and departure times.
4. Set +10 minutes maximum extra travel.
5. Analyze the day.
6. Show routes evaluated, day plans tested and feasible plans.
7. Show before/after modeled exposure with zero appointment changes.
8. Open What Changed and Why.
9. Use the optimized plan.

With `DemoMode=true`, external route/environment values are controlled while API Gateway, Lambda, Step Functions and DynamoDB remain the product path.
